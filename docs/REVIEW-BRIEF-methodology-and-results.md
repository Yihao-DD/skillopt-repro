## 1. 研究命题

SkillOpt 把"给冻结 agent 优化一份技能文档"做成深度学习式的单点优化：每步 rollout → minibatch 反思 → 受 edit-budget 约束的 bounded edits → **在 selection 集上 strict-`>` 验证门**接受/拒绝 → 跨 epoch slow/meta update。本质是**带噪声验证门上的不可逆坐标上升**。

我们的命题：用 **Quality-Diversity（MAP-Elites archive）替换单点 current-skill**——按行为描述子把候选分格、每格各留一个 elite、UCB 选 parent 继续爬。核心假设：**archive 保留 greedy 会丢弃的"踏脚石"技能，让优化器爬到一个更高的最终单技能**。

关键红线（贯穿始终）：纯 API 无 GPU；**K=1 时 QD 必须精确退化为原文 SkillOpt**（特例等价）；两臂**等昂贵评估预算**。

## 2. 方法论演进——我们犯的三个错，以及如何纠正（这是本文重点）

这个项目的价值有一半在"我们怎么发现自己一直在高估 QD"。三个错误，逐层剥开：

### 错误一：把 QD 当 ensemble / 事后选择
早期我们用缓存的最终技能，测"从 QD 产出的多个技能里选/路由能否赢单技能"。**这测的是 ensemble，不是 SkillOpt 的机制**。SkillOpt 是单文档迭代积累可迁移 guidance——QD 的增益若存在，必来自**搜索动力学**（archive 帮优化器爬得更高），而非事后挑技能。
- 纠正：这条路我们**测充分了，是负结果**（见 §3）；但认清"它根本不是 QD 命题"。

### 错误二：对照基线被阉割 + 评估口径有偏（**最严重**）
我们最初造了一个简化的搜索循环，**绕过了 SkillOpt 原文完整实现**。后果是三重偏差，全部**同向高估 QD**：
- **合并集**：我们让"生成候选"和"验证门"用同一个集（原文是 train 生成 / val 门，分离）→ 放大选择税，而 QD 恰好抗选择税 → 利好 QD。
- **阉割 slow/meta update**：原文默认开，其消融在 SpreadsheetBench 上值 **+22.5pts**；我们没实现 → greedy 基线被砍 22 分。
- **阉割 rejected buffer**：原文标配，消融值 **+4.6pts**；我们也没默认开 → greedy 又被砍 4.6 分。

合起来：greedy 被砍掉约 **27pts** 的原文组件，再叠加有利于 QD 的评估口径。**所以我们早期所有"QD 赢"（合并集口径下 +12.5 / +4.8 pts，公司在 qwen3.5 上 +2.1pts，多 seed pooled McNemar 显著）——对原文 SkillOpt 完全不可信。**
- 纠正：**铁律——对照基线必须完全忠于原文，绝不能阉割**。我们随后忠实化：三集分离、补回 slow/meta、补回 rejected buffer，两臂只在 archive 一个维度不同、其余逐字对称（防"为赢堆 buff"）。

### 错误三：binning 塌缩 → QD 搜索从没被公平跑过
即使忠实化了，还有个隐藏问题：QD 的行为描述子用固定 [0,1] 均匀分格，但真实候选的行为分布很窄 → **archive 塌成 2-4 格**（满格是 16）。archive 一塌，K>1 就退化成"近 greedy + 一个更差的 gate"。**也就是说，QD 的搜索机制（多格踏脚石 + 跨格迁移）从来没有在一个真正展开的 archive 上运行过。**
- 离线验证：同样的候选点、同一描述子，固定均匀分格只占 2-4/16，改成按搜索分布自适应分位分格占 **13-15/16**。塌缩是分格假象，不是行为同质。
- 纠正：实现自适应分格（warmup 校准分位切点、frozen、不额外花评估 → 等预算红线保住），让 archive 真正展开。

**一句话总括**：我们花了很多轮才认清——"QD 赢"曾建立在阉割基线 + 有偏口径上（不可信），"QD 输"曾建立在塌缩 archive 上（QD 没真跑）。**两个方向的旧结论都站不住。**

## 3. 结果分层（诚实，按可信度）

| 命题 | 测了吗 | 结果 | 可信度 |
|---|---|---|---|
| **ensemble / 路由**（事后选/路由最终技能） | ✅ 充分（5 折 CV，大样本） | **负**：样本外 **+0.01 ± 0.08**（有折 −0.12）；in-sample 看似巨大的互补 headroom 是"选择性海市蜃楼"，不可泛化 | 高（但**非 QD 命题**） |
| **"QD 赢 greedy"**（合并集口径，含公司 venus 正结果） | ✅ 多次 | 名义上 +2~12pts、统计显著 | **对原文不可信**（基线阉割 + 口径有偏） |
| **"QD 输 greedy"**（早期小预算负结果） | ✅ | greedy 略胜 | **不可信**（archive 塌缩，QD 没真跑） |
| **search dynamics**（archive 踏脚石 → 更高单技能，忠于原文 + 展开 archive） | ❌ **从没公平测** | **未知** | —— |

**净结论：在 SkillOpt 上"QD 能不能赢"目前是未经证明的开放问题。** 唯一在严格意义上被否定的是 ensemble 路（而它不是 QD 命题）。

## 4. 为什么 greedy 不是无敌的（机制论证，支持"值得再测一次"）

原文 greedy = 噪声 val 上的不可逆 strict-`>` 坐标上升，有三个可证的次优口子：
1. **val 过拟合棘轮**：只接受 val 严格变好的 edit 并永久锁定 → 卡在 val-optimum（可能 < test-optimum）。
2. **过不去中性平台**：val 中性但能解锁后续大改进的侧移，被 strict-`>` 拒绝。
3. **路径依赖**：第一个 improving edit 锁定 basin，错过更优 basin。

QD 的 per-cell 门**严格更宽松**（候选只需赢自己那格）→ 保留 greedy 丢弃的踏脚石 → UCB 从踏脚石继续爬 → 机制上能逃这三个陷阱。**这个机制真实存在，只是从没在非塌缩 archive 上运行过。**

⚠️ 诚实保留：ensemble 路的样本外负结果，**弱暗示**搜索多样性也可能只是噪声；不能据此断定 search dynamics 无效，但也不能无视——必须公平跑一次才知道。

## 5. 当前状态 + 预登记预测

- **忠实化已完成**：三集分离 + slow/meta update + rejected buffer 两臂对称，K=1 == 原文 SkillOpt。
- **binning 已修**：自适应分位分格，archive 能真正展开。
- **正在进行**：第一次公平的 search-dynamics 付费对照（faithful K=1 vs K>1，在 greedy 会 plateau 的预算下，比**单个最好技能的 held-out 分**，多 seed + 配对统计）。

**预登记预测**（防事后挪门柱）：忠于原文后 QD 优势很可能**缩小**——greedy 补回组件后更强、过拟合更轻、QD 的正则化红利更小。中心预测 QD−greedy **+0~3pts、可能不显著**（~50%）；持平/负 ~30%；稳定显著 +2~4pts ~20%。**无论结果都有产出**：QD 真有增量 = 经得起忠实化的硬结果；无增量 = "评估协议系统性高估 skill-optimization 新方法"的方法论警示（同样可发表）。
