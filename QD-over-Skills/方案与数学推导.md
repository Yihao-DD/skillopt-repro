# QD-over-Skills:完整方案与数学推导

> v0.2 — 在 SkillOpt 上做 Quality-Diversity 搜索;纯 API、不用卡;变异 = optimizer 的 top-k/p「瞄准着采」,选择 = 行为分格 + 格内信任域 gate。本稿含数学形式化。
>
> **诚实分级**:本稿区分三类结论——(A) **已证**(干净命题,文中给证);(B) **集中性论证**(需声明假设,文中给草证);(C) **设计原则 / 待经验验证**(明确标注,不冒充定理)。见 §9。

---

## 0. 一句话

**把 SkillOpt 的「单点贪心」换成 QD 档案:用 optimizer 的 top-k/p 采样(瞄准档案里没有的行为)做变异,用行为描述子分格,用「格内严格 ≻」做选择;在行为空间去重以把昂贵评估只花在真不同的候选上。从而在不拆 SkillOpt 稳定性(其 $K=1$ 特例)的前提下逃出局部最优。**

---

## 1. 符号与问题设定

- $M$:frozen target 模型(API,**钉死版本**);$O$:optimizer 模型(API);$h$:harness。三者在训练中固定。
- 技能 $s \in \mathcal{S}$(自然语言文档空间)。任务 $x$;划分 $D_{tr}, D_{sel}, D_{test}$。
- 单次执行(SkillOpt 式):$(\tau(s;x), r(s;x)) = h(M,x,s)$,$r \in [0,1]$。
- **适应度(昂贵)**:在选择集上的平均分
$$
f(s) \;=\; \frac{1}{|D_{sel}|}\sum_{x\in D_{sel}} r(s;x)\;\in[0,1].
$$
  每求一次 $f(s)$ = 一整轮 frozen-agent rollout,**这是成本瓶颈**。
- 原子编辑算子 $\{\texttt{append},\texttt{insert},\texttt{replace},\texttt{delete}\}$;编辑距离 $\rho(s,s')$ = 互相转换所需最少原子编辑数。
- 编辑预算(文本学习率)$L_t\in\mathbb{N}$:第 $t$ 步对任一父技能最多施加的编辑数。

**纯 API 约束**:$f$、$\tau$、descriptor 全部只用 API 可观测量(轨迹 + 可选 logprobs),**不依赖隐藏激活**;故 Tier-C(SAE/探针)移入 future work。

## 2. 方法总览与算法

四个可替换组件:**变异算子** $V$、**描述子** $b$、**选择算子(档案更新)** $U$、**预算调度** $\Pi$。一次迭代:

```
状态:档案 A_t（每格存 elite + 其 f 值）、进度窗、rejected buffer、缓存/代理
1. Rollout：current skill 在 D_tr 批上跑 → 轨迹 τ、分
2. 瞄准着采(变异 V)：把 A_t 的各格行为摘要喂给 O，
   要求提 N 条 edit：部分改进当前打法，≥M 条走与档案不同的策略
   → 候选 {s̃_1,…,s̃_N}（生成廉价：O 推理 + API 不限量）
3. 廉价指纹 + 去重：每个候选只在 probe 集 P（|P|=m，如 3 道）跑 → 算 b̂(s̃_i)
   在 b 空间内按半径 ε 聚类，每簇留一代表 → N′ 个行为互异候选
4. 缓存/代理分诊：命中缓存取旧分；代理预测器对 N′ 个排序
5. 全量评估（昂贵）：仅对 N′ 个代表算 f(·)（在 D_sel 上）
6. 格内选择（U）：对每个评过的候选，定位 j*=cell(·)，
   若 f > E_t(j*)（严格）或该格空 → 收为该格新 elite；否则进 buffer
   全局最优 s*_t = argmax_j E_t(j)
7. 调度 Π + 自适应 k：全局最优稳涨 → 小 N、走 exploitation；
   plateau（窗 W 内不涨）→ 调大 N、加大“不同策略”比例、并切到另一格 elite 去精修
→ 回到 1
```

$K=1$(单格)时,该循环**精确退化为 SkillOpt**(见 §3.2 命题 3)。

## 3. 数学形式化

### 3.1 行为描述子与分格(机制二)

**定义 3.1(行为描述子)** 取 probe 集 $P\subset D_{tr}$,$|P|=m$。设有界轨迹特征 $\phi(\tau)\in[0,1]^p$(工具调用分布、步数、是否验证、错误模式画像等)。描述子
$$
b(s)\;=\;g\!\Big(\underbrace{\textstyle\mathbb{E}_{x\sim P}\,\phi(\tau(s;x))}_{=: \mu(s)\in[0,1]^p}\Big)\in\mathcal{B}\subseteq\mathbb{R}^d,
\qquad
\hat b(s)=g\!\Big(\tfrac1m\textstyle\sum_{i=1}^m \phi(\tau(s;x_i))\Big),
$$
其中 $g$ 为投影:Tier-A 手设 $d{=}2{\sim}3$ 个可解释轴;Tier-B 学出嵌入(对比/降维)。**分格** $\mathcal{B}$ 划分为单元 $\{c_1,\dots,c_K\}$,$\mathrm{cell}(s)=c_j$ s.t. $b(s)\in c_j$。

**命题 3.2(描述子稳定性,集中性论证 B)** 设 $g$ 为 $L_g$-Lipschitz,$\phi\in[0,1]^p$,probe 任务 i.i.d.。则对任意 $\epsilon>0$,
$$
\Pr\big[\,\|\hat b(s)-b(s)\|_2>\epsilon\,\big]\;\le\;2p\,\exp\!\Big(-\tfrac{2m\,\epsilon^2}{p\,L_g^2}\Big).
$$
*证(草).* 逐坐标 $\tfrac1m\sum_i\phi_k(\tau(s;x_i))$ 是 $[0,1]$ 有界量的均值,Hoeffding 给 $\Pr[|\hat\mu_k-\mu_k|>t]\le 2e^{-2mt^2}$。并联 $p$ 维并用 $\|\hat\mu-\mu\|_2\le\sqrt p\,\max_k|\hat\mu_k-\mu_k|$ 与 $g$ 的 Lipschitz 性($\|\hat b-b\|\le L_g\|\hat\mu-\mu\|$),令 $t=\epsilon/(L_g\sqrt p)$ 即得。∎

**推论**:描述子误差以 $O\!\big(L_g\sqrt{p/m}\big)$ 收缩;**probe 越大、特征越少越紧**。实践:控制 $p$、选区分度高的 probe。

**判别性(设计原则 C,非定理)** 定义行为距离 $d_{\mathcal B}(s,s')$ 为两者轨迹特征分布间距离(如工具调用分布的 TV / Wasserstein)。**要求 $b$ 近似双 Lipschitz**:存在 $0<\alpha\le\beta$ 使 $\alpha\,d_{\mathcal B}\le\|b(s)-b(s')\|\le\beta\,d_{\mathcal B}$。
- **template collapse 的形式刻画** = 上界被破坏:$\|b(s)-b(s')\|$ 大而 $d_{\mathcal B}(s,s')$ 小(文字异、行为同却被分到不同格)。双 Lipschitz 上界**禁止**之。
- 这是**待经验验证**的目标,由 §5 的「文字异/行为同」「文字同/行为异」对照实验检验,而非此处证明。

### 3.2 格内信任域接受规则(机制一)

**定义 3.3(档案与更新算子 $U$)** 第 $t$ 步档案 $A_t:\{1,\dots,K\}\to\mathcal S\cup\{\bot\}$。格分数
$$
E_t(j)=\begin{cases}f(A_t(j)) & A_t(j)\ne\bot\\[2pt] -\infty & A_t(j)=\bot.\end{cases}
$$
候选 $\tilde s$,$j^\*=\mathrm{cell}(\tilde s)$。**接受规则(严格 ≻,平局拒)**:
$$
A_{t+1}(j)=
\begin{cases}
\tilde s, & j=j^\*\ \text{且}\ f(\tilde s)>E_t(j^\*),\\
A_t(j), & \text{否则}.
\end{cases}
$$
全局最优 $s^\*_t=\arg\max_j E_t(j)$,值 $E^\*_t=\max_j E_t(j)$(= 导出的 `best_skill.md`)。

**命题 3.4(格内单调 / 永不漂移,已证 A)** 对每个 $j$,$E_{t+1}(j)\ge E_t(j)$。
*证.* 仅 $j^\*$ 可变,且当且仅当 $f(\tilde s)>E_t(j^\*)$ 时 $E_{t+1}(j^\*)=f(\tilde s)>E_t(j^\*)$;余格不变。∎
→ 复现 SkillOpt「不悄悄漂移」,且因严格 ≻ 而**平局拒**,只是现在作用于**每个行为格**。

**命题 3.5(全局单调 / 部署不退化,已证 A)** $E^\*_{t+1}\ge E^\*_t$。
*证.* $E^\*_{t+1}=\max_j E_{t+1}(j)\ge\max_j E_t(j)=E^\*_t$,由命题 3.4 每格不降。∎

**命题 3.6(对 SkillOpt 的归约,已证 A)** 取 $K=1$:档案退化为单 elite,$E_t(1)$ 即「当前/最佳分」,规则 $f(\tilde s)>E_t(1)$ 即 SkillOpt 的严格 gate。**故本方法严格推广 SkillOpt;SkillOpt = 单一行为格的本方法。**
→ **四面墙在 $K=1$ 处即 SkillOpt 本身,从而被保留**;$K>1$ 只「在格间加宽度」。

**命题 3.7(信任域 / 有界步长,已证 A)** 任一被接受候选 $\tilde s$ 与其父 $s_{\mathrm{par}}$ 满足 $\rho(\tilde s,s_{\mathrm{par}})\le L_t$。故同一格内相邻 elite 在编辑空间相距 $\le\sum L_t$,优化历史保持有意义。**宽度(占用格数)增长,而每步编辑步长 $\le L_t$ 不变。**

**与「朴素松 gate」的对照(核心区别)**
- 朴素探索:全局接受 $f(\tilde s)\le E^\*_t$ ⇒ 可令 $E^\*_t$ 下降 ⇒ 漂移(消融里 $-22.5$ 的失败)。
- 本规则:**从不接受格内下降**(命题 3.4),却保留「全局更差、但在其所属空格/格内最佳」的行为新候选 ⇒ 该候选可在本格被精修 ⇒ 最终可越过 $E^\*_t$。**逃逸来自分格结构,而非接受下降。**

**命题 3.8(逃逸容量,存在性;条件需经验满足,A+C)**
设变异算子可在任一被保留技能的 $L_t$ 邻域内提任意编辑。记贪心($K{=}1$)可达集 $\mathcal R_{\mathrm{greedy}}(s_0)$ = 从 $s_0$ 出发**单调不降**链所及技能;QD 可达集 $\mathcal R_{\mathrm{QD}}(s_0)$ = 各格内单调链经跨格候选连接之并。则
$$
\mathcal R_{\mathrm{greedy}}(s_0)\subseteq \mathcal R_{\mathrm{QD}}(s_0),
$$
且当存在更高适应度技能 $s^\dagger$,其到 $s_0$ 的任一路径都经过一个「适应度低谷」中间点 $s_v$(即 $f(s_v)<f(s_0)$)**且 $\mathrm{cell}(s_v)\ne\mathrm{cell}(s_0)$** 时,包含**严格**($s^\dagger\in\mathcal R_{\mathrm{QD}}\setminus\mathcal R_{\mathrm{greedy}}$)。
*证(草).* 贪心拒一切非改进,$s_v$ 必被拒,故 $s^\dagger$ 不可达;QD 中 $s_v$ 落入异格(空或被其超越)而被保留,再在该格继续精修可达 $s^\dagger$。∎
> **关键依赖(诚实)**:逃逸**能否真发生**还取决于 (i) 变异是否真提出 $s_v$,(ii) 描述子是否把低谷路径与起点分到**不同格**(否则低谷仍在同格内,格内贪心照样过不去)。**这把机制一的逃逸能力,严格地系在机制二的描述子质量上**,且二者均在 §5/Phase 0 经验检验。

### 3.3 变异算子:top-k/p 瞄准着采(机制一·变异半)

optimizer 在上下文(轨迹 $\tau$、档案摘要 $\mathcal A_t$、瞄准指令 $a$)下诱导编辑分布 $\pi_O(\cdot\mid\tau,\mathcal A_t,a)$。top-$k$/$p$ 截断后采 $N$ 条:
$$
\{\tilde s_1,\dots,\tilde s_N\}\ \sim\ \mathrm{trunc}_{k\,\text{或}\,p}\,\pi_O(\cdot\mid\tau,\mathcal A_t,a).
$$
**瞄准** = 令 $a$ 含「档案已有策略 + 提与之不同打法」的指令,使分布向新行为偏移(novelty 作为 **prompting 信号**,零额外评估)。$k/p$ 是单一可控旋钮(变异强度,类比 temperature)。
> 注:纯 top-$k$/$p$ 是**局部**变异(扎堆在 mode)。瞄准 + §3.4 去重共同把它从「撒网」改造成「定向且不重复付费」。

### 3.4 样本高效与成本(机制三)

**去重→成本分解.** 候选 $N$ 个:廉价 probe 指纹(代价 $N\!\cdot\! m$ 道**便宜**题)→ 按半径 $\epsilon$ 聚类,设触及的不同格数为
$$
N'\;=\;\big|\{\mathrm{cell}(\tilde s_i):i\le N\}\big|\;\le\;\min(N,K).
$$
每格只全量评估其 probe-最佳代表。则**每步昂贵代价**
$$
C^{\mathrm{exp}}_{\text{step}} = N'\cdot|D_{sel}| \;\le\; K\cdot|D_{sel}|,
\qquad
C^{\mathrm{cheap}}_{\text{step}} = N\cdot m .
$$

**命题 3.9(ROI 上界,已证 A)** 无论生成多少($N\to\infty$),每步昂贵代价被**行为多样性**封顶:$C^{\mathrm{exp}}_{\text{step}}\le K|D_{sel}|$。$T$ 步总昂贵代价 $\le T K|D_{sel}|$,对比朴素全评估 $TN|D_{sel}|$,**节省因子 $\ge N/\min(N,K)$**。
> 这是对「投入产出不成正比」担心的形式回答:**昂贵评估只与不同打法数挂钩,不与采样数挂钩**;descriptor 兼任去重器,自己挣回成本。
> *数值例*:朴素 $N{=}10$ 全评 $=10{\times}20{=}200$;本法 probe $10{\times}3{=}30$(便宜)+ 去重剩 $3$ + 全评 $3{\times}20{=}60$(贵)。贵开销 $200{\to}60$。

**预算调度 $\Pi$(原则性启发,标注 C — 非已证 regret 界).** 固定昂贵预算 $B$,在「填新格(探索)」与「精修现有 elite(利用)」间分配。把每格 $j$ 视作一臂,UCB 式打分:
$$
\mathrm{score}(j)=\widehat{\Delta E^\*_j}\;+\;\beta\sqrt{\tfrac{\log t}{n_j}}\;+\;\gamma\cdot\mathrm{nov}(j),
$$
$\widehat{\Delta E^\*_j}$=代理预测的「改进该格对全局最优的期望增益」,$n_j$=该格评估次数,$\mathrm{nov}(j)$=该格到已占用区的距离。每次把评估投给 $\arg\max_j\mathrm{score}(j)$。**plateau 触发**:$E^\*_t$ 在窗 $W$ 内不涨 ⇒ 增大 $\gamma$(偏向探索)、并切换在修 elite。
> **诚实**:证明该策略的 sample-complexity / regret 界本身是一篇论文量级的工作,此处仅作有依据的启发式,列为 §9 待推导项。

## 4. 与已有工作的精确 diff

| 邻居 | 它做了什么 | 本工作差别 |
|---|---|---|
| **SkillOpt**(父) | 贪心 gate、单一最优 | 本法 = 其 $K>1$ 推广(命题 3.6);加档案逃局部最优 |
| **EvoSkill**(SkillOpt baseline) | held-out + **Pareto** 选择 | 「skill 加 Pareto」已做;本法越过 Pareto → **行为多样性**(QD≠多目标) |
| **AlphaEvolve / FunSearch** | QD 进化**代码** | 假设 fitness 廉价;本法解**昂贵评估**(命题 3.9) |
| **QD-for-prompts** | 对 prompt 做 QD | 本法优化**持久、可验证、可迁移 skill** + SkillOpt 纪律 |
| **PBT+LLM(LPBRL 等)** | LLM 驱动 PBT 调 RL 超参 | PBT 作最简实例;贡献在**行为描述子 + 格内信任域规则** |

**开放缺口(= 贡献)**:① 原则性 skill 行为描述子(§3.1);② 昂贵评估下的样本高效 QD(§3.4);③ 探索 ⊥ 稳定 gate 的形式解(§3.2,命题 3.4–3.8)。

## 5. 实验设计

- **Benchmarks**:SpreadsheetBench + LiveMath = 敏感主战场;SearchQA = 饱和参照(勿当主战场)。
- **必打 baseline**:SkillOpt(贪心,$K{=}1$)与 EvoSkill(Pareto)。
- **关键消融**:① QD 去描述子(随机分格)→ 证描述子有用;② QD 用**文字**描述子 → 证「行为」才对(直击 template collapse);③ 只 PBT vs 完整 QD。
- **描述子验证实验**(检验 §3.1 判别性 C):造「文字异/行为同」与「文字同/行为异」技能,证行为描述子判对、文字描述子判错。
- **赢的判据**:(i) 在「楔子」上逃出 SkillOpt 卡死的局部最优;(ii) 档案产物迁移 $\ge$ baseline;(iii) **同等昂贵评估预算**下成立(命题 3.9 让此可行,**不可谈判**)。
- **模型/算力**:target + optimizer 皆 API,**钉死版本**;harness 工具执行走 CPU。无需 GPU。

## 6. 分阶段路线

- **Phase 0(2–3 周,验 payoff 与可行性)**:复现 SkillOpt;**同时回答**——(a) 贪心是否卡局部最优(payoff 在不在)、(b) 瞄准着采能否产出**行为不同**候选(命题 3.8 依赖 i)、(c) 描述子 + probe 能否把真/假不同分开(依赖 ii)。任一为否即廉价止损或转向。
- **Phase 1(低风险结果)**:skill 种群 + 格内 gate(粗描述子),证「楔子上种群续爬、贪心 plateau」。**保底可发 + 消融基线。**
- **Phase 2(冲刺)**:学出来的行为描述子(Tier-B)+ 完整 §3.2–§3.4,打 SkillOpt 与 EvoSkill,验迁移。

## 7. 纯 API 约束(本稿默认)

- target/optimizer 全走 API;**钉死带日期快照版本、紧时间窗内跑完**(或用 API 托管的固定开源权重模型),以保「frozen」诚实。
- 描述子只用 API 可观测量:轨迹 $\tau$ +(若 API 暴露)token-level **logprobs**(可把导师想要的「entropy」信号无卡捞回,作可选加料)。
- **Tier-C(SAE/探针读激活)需本地模型,移入 future work**(代价:暂放下可解释性内部信号角度)。

## 8. 风险与兜底

- **描述子(§3.1)是生死手**:成 → 越过 EvoSkill/SkillOpt 的干净 QD-for-skills;不成 → 退回 **Phase 1 种群结果**。
- **逃逸依赖(命题 3.8 的 i/ii)与 probe 代表性**:Phase 0 廉价可测;不满足则换变异引导 / 换 optimizer / 承认任务单 basin 而转向。
- **同等预算公平性(命题 3.9)**:不满足则 headline 不可信。
- 整体:PBT 兜底(保底产出)+ 描述子高天花板 + 纯 API 低门槛 → 适合 PhD 申请季。
