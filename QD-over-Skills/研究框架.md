# QD-over-Skills:在 SkillOpt 上注入探索的研究框架

> 草案 v0.1 —— 用于自己理清思路 / 和导师对齐分工。每一节都可单独深挖。

---

## 0. 一句话定位

**在 agent skill 上做 Quality-Diversity 搜索:用一条「保信任域的格内接受规则」替代 SkillOpt 的全局贪心 gate,用一个「从行为轨迹学出的 behavior descriptor」来分格,并在「昂贵的 frozen-agent 评估」下做到样本高效——从而在不拆掉 SkillOpt 稳定性机制的前提下,逃出它的局部最优。**

核心张力(整篇论文的轴):
**怎么在不松垮那道「严格大于、平局拒」的 gate(以及其余三面承重墙)的前提下,注入探索?**

---

## 1. 问题陈述

- **SkillOpt 是什么**:把一份自然语言 skill 文档当作 frozen agent 的「可训练外部状态」,用 DL-optimizer 的纪律去优化(学习率=edit 预算、validation gate、动量=慢更新)。产出一份 `best_skill.md`,部署零推理开销、不改权重。
- **它的软肋**:只保留**一个** current skill,且候选必须**严格超过它**才被接受。这是一条**单点贪心爬山**——任何「行为不同但当下分更低」的候选(局部最优的垫脚石)都被丢弃。→ **易陷局部最优,并主动丢弃多样性。**
- **它的四面承重墙**(由 §4.2 消融证明,**动不得**):
  1. 有界文本学习率(edit budget `L_t`)
  2. 严格 validation gate(`>`,平局拒)——买到「不漂移 + 干净负反馈 + 可审计」
  3. rejected-edit buffer(失败变负反馈)
  4. 按 epoch 的慢/meta 更新 + 受保护字段(去掉它 SpreadsheetBench −22.5,全消融最大跌幅)
- **真问题**:不是「加一个探索模块」,而是**解决张力**——探索几乎每一项朴素实现都在拆墙。

---

## 2. 核心主张(reframe)

把 SkillOpt 的「只留一个最优」换成 **QD / MAP-Elites 的「按行为分格、每格留该格最优」**(一个奖杯架)。

把导师最初那三个机制归位:
- **QD / MAP-Elites = 骨架**(统领框架)
- **PBT = 最简实例 / 低风险兜底结果**(小档案 + exploit-explore)
- **entropy & novelty = descriptor 的多样性/新颖度度量**(作用在行为指纹空间,不作用在文字上)

→ 不要三者并排各做一套;做一个连贯系统。

---

## 3. 方法:三个机制

### 机制一:保信任域的格内接受规则
- **改法**:维护一个按 behavior descriptor 分格的档案,每格保留该格最优 elite;候选落入其格,`score > 该格 elite` 才接受;**空格直接收下**(= 探索)。部署仍只发全局最优 elite。
- **为何保住墙又加探索**:`>` gate 完整保留在**每格内部**(格内永不漂移、负反馈干净、可审计);探索来自「养着一堆活的格子」,而非松 gate。**格内严格、格间多样。**
- **要形式化**:档案更新算子的**每格 elite 单调不降** + **全局最优单调不降**;信任域性质(每步 ≤ `L_t` edit,格内相邻 skill 仍接近)。**「档案只在格间加宽度,不在格内加步长。」**
- **设计决定**:允许跨格变异/重组,但接受仍走格内 gate(重组候选也得赢下某格)。
- **风险**:最低,安全理论贡献。

### 机制二:从行为轨迹学出的 behavior descriptor(命门)
- **它回答**:给一份 skill,怎么决定它落哪一格(= 风格标签从哪来)。
- **大坑**:用 skill **文字**特征分格 → **template collapse**(文字多样 ≠ 行为多样,假多样)。
- **正解**:用 agent **实际行为(轨迹 τ)** 打标签。**抓手:SkillOpt 管线本就把 τ 记得极细,原材料现成。**
- **行为指纹候选特征**:工具使用画像(先勘察 vs 一把梭)、轨迹步数/结构、是否验证、错误模式画像。
- **指纹 → 格坐标(三档)**:
  - **A 档**:手挑 2 根可解释轴(如「勘察程度 × 验证程度」)→ 2D 网格。**起步基线。**
  - **B 档**:学出来的嵌入/降维(行为相似自动靠近)。**真正的贡献。**
  - **C 档**:用探针 / SAE 看模型内部激活当指纹。**最有野心,接 interpretability 老本行。**
- **entropy/novelty 落点**:novelty = 到档案已有指纹的距离;RND = 行为预测误差大 = 新。
- **验证实验(能卖的)**:造「文字异/行为同」与「文字同/行为异」的 skill,证明行为 descriptor 判对、文字 descriptor 判错。
- **风险**:最高、最值钱、生死手。**兜底**:先用 A 档跑通,再证 B/C 更好。

### 机制三:昂贵评估下的样本高效 QD
- **问题**:QD 要考海量候选填档案,但「考一份 skill = 一整轮昂贵 rollout」。朴素 QD 会烧穿预算。**这也是不能直接搬 AlphaEvolve/FunSearch 的原因**(它们假设 fitness 便宜)。
- **省考试的招**:
  1. 缓存(skill-hash,SkillOpt 已有),不重考。
  2. 快筛:先用 2–3 道 probe 题试,差的直接淘汰;**probe 跑出的 τ 同时供机制二算指纹(一鱼两吃)**。
  3. 代理模型:从指纹「猜分」,只在不确定时才真考(BO 式)。
  4. 并行评估(2×RTX 5090)。
  5. 智能预算调度:把考试名额投给最可能涨/最新颖的格(机制二的 novelty 分路由预算)。
- **要形式化**:固定考试预算下,「开新格 vs 精修旧格」的分配策略(bandit/BO 味)。
- **生死点**:**必须在「同等评估预算」下打赢 SkillOpt**,否则「多烧算力当然赢」一句话被毙。**机制三让胜仗算数。**
- **风险**:中等;借 surrogate-assisted QD 现成思路,工程+适配,可辩护。

### 三者如何咬合(一个系统,不是三个螺栓)
- 机制二定义格 → 机制一往格里收;
- 机制二的 novelty 分 → 路由机制三的评估预算;
- 机制三的 probe rollout 产出的 τ → 正是机制二算指纹的料(共享算力);
- 机制一的格内单调性 → 全系统稳定、保住四面墙的根基。

## 4. 与已有工作的精确 diff(可防 scoop)

| 邻居 | 它做了什么 | 我和它的差别 |
|---|---|---|
| **SkillOpt**(父工作) | 贪心 gate、单一最优 skill | 我把单点贪心换成 QD 档案、逃局部最优 |
| **EvoSkill**(SkillOpt 自己的 baseline) | 已用 held-out 验证 + **Pareto 前沿**选择 | 「给 skill 加 Pareto」已被做;**我必须越过 Pareto** → 行为多样性 / QD,而非多目标权衡 |
| **AlphaEvolve / FunSearch** | QD/进化造**代码** | 它们假设 fitness 廉价确定;**skill 评估昂贵**(机制三正是解这个) |
| **QD-for-prompts**(MAP-Elites prompts、红队 QDRT 等) | 对 prompt 做 QD | 我优化的是**持久、可验证、可迁移的 skill 文档**,且带 SkillOpt 的稳定纪律 |
| **PBT + LLM**(LPBRL 等) | LLM 驱动 PBT 调 RL 超参 | 我把 PBT 当最简实例;贡献在**行为 descriptor + 保信任域规则** |

**开放缺口(= 我的贡献)**:① 原则性的 skill **行为 descriptor**(两文献皆未解);② **昂贵评估下**的 QD;③ **探索 ⊥ 稳定 gate** 的形式化解(格内 trust-region 规则)。

## 5. 实验设计

- **Benchmarks**:**SpreadsheetBench + LiveMath = 敏感主战场**(对过度编辑敏感、提升空间大);**SearchQA = 饱和参照**(近天花板,别当主战场)。
- **必打 baselines**:**SkillOpt(贪心 gate)** 和 **EvoSkill(Pareto)** 都要打。
- **关键消融**:
  - QD 去掉 descriptor(随机分格)→ 证 descriptor 有用;
  - QD 用**文字** descriptor → 证「行为」才对(直击 template collapse);
  - 只有 PBT vs 完整 QD → 证全 QD 比种群多出价值。
- **赢的判据**:
  1. 在「楔子」上逃出 SkillOpt 卡住的局部最优(它 plateau,我继续爬);
  2. 档案产出的 skill **迁移**≥ baseline(= 哲学站得住的指纹);
  3. **同等评估预算**下成立。
- **模型 / 算力**:frozen target = 开源小模型(Qwen2.5-7B,塞进单卡 32G);optimizer = 导师 API 的前沿模型。2×RTX 5090 并行跑 rollout。档案先小(十几格),靠缓存+快筛压成本。

## 6. 分阶段路线

- **Phase 0 — 复现 + 找楔子(2–3 周)**:复现 SkillOpt(`aka.ms/SkillOpt`);**关键产出 = 一个「贪心 gate 必卡死、QD 能逃」的具体场景**(如:需要两种不同程序策略,通往更优策略的中间版本会暂时掉分)。没有楔子,立不住论。
- **Phase 1 — 低风险结果(skill 种群 + 格内 gate,PBT 版)**:先不碰难 descriptor,用粗分格 + exploit-explore,证明在楔子上「种群持续爬、贪心早早 plateau」。**可较快拿到的第一个可发结果 + 后续消融基线。**
- **Phase 2 — 冲刺(学出来的行为 descriptor + 保信任域格内规则 + 样本高效)**:装齐三个机制,打 SkillOpt 和 EvoSkill,做关键消融,验迁移。

---

## 7. 需要形式化的交付物(「推公式」清单)

1. **格内接受算子**:定义 + 每格/全局 elite 单调不降 + 信任域性质(机制一)。
2. **behavior descriptor `b(s)`**:定义 + 稳定性(probe 子样本方差低)+ 判别力(行为同→同格,行为异→异格)(机制二)。
3. **预算分配策略**:固定评估预算下「探新格 vs 精修」的分配 + 理论依据(机制三)。

---

## 8. 风险与兜底

- **机制二(descriptor)是生死手**:做成 → 越过 EvoSkill/SkillOpt 的干净 QD-for-skills;做不成 → 退回 **Phase 1 的「种群逃局部最优」稳妥结果**。
- **机制三的「同等预算」公平性不可谈判**:否则 headline 不可信。
- **整体**:有 PBT 兜底(保底产出)+ descriptor 高天花板(亮点上限)→ 适合 PhD 申请季。

---

## 9. 明确不做的事(每条对应一个论文发现)

- **不**只加 Pareto / 多目标(EvoSkill 已做;QD ≠ Pareto)。
- **不**全局松 gate 接受不涨分候选(= §4.2 惩罚的漂移,−22.5)。探索只走「格内 gate + 档案」。
- **不**用文字表面熵/新颖度(template collapse)。一切多样性从行为 τ 量。
- **不**动慢更新 + 受保护字段(承重墙;可升级为「每格受保护 elite」)。

---

## 10. 可投出的一句话主张

> *MAP-Elites over agent skills with a learned behavior descriptor and a trust-region-preserving acceptance rule, made sample-efficient under expensive frozen-agent evaluation.*
